# Sprints

Una consigna por sprint: `sprint-N.md`, con el enunciado **tal cual lo entregó la cátedra**,
sin reinterpretar. La interpretación va en `sprint-N-backlog.md`, aparte: qué se compromete,
en qué orden y qué se recorta.

Por qué vive en el repo: la consigna define el alcance, y versionarla al lado del código deja
registro de qué se pedía cuando se escribió cada cosa.
